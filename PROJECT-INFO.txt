🚀 HOW TO RUN
═══════════════════════════════════════════════════════════════════════════════

METHOD 1: Direct Browser
   → Open index.html in your browser

METHOD 2: Python Server
   → python -m http.server 8000
   → Open http://localhost:8000

METHOD 3: Node.js Server
   → npx serve
   → Follow the URL shown
